All For One

Used by: All For One

Steals the quirks of others to use as your own or give to others.

Passives

  • All For One ①[Combining Quirks] Behavior changes depending on the combined skills, and there are several main attack types. If several apply, the main Quirk chosen first takes priority.
  • Combine Quirks[Passive] Double-tap Shift to open the Quirk combination GUI. Select the Quirks to use (multiple allowed), write a skill name in the bottom-left field, and press the check button at the bottom right to create the skill.
