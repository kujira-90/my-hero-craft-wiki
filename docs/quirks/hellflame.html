Quirks / Heroes

Hellflame

Used by: Endeavor

Produces powerful flames like hellfire.

Passives

  • Hellflame ①[Overheat] The gauge rises each time you use the Quirk. At MAX, Quirk damage and mobility drop.
  • Thrust[Passive] Double-tap Shift to fly. The gauge rises while flying. Press the sprint key while looking up to rise, using more gauge than usual.
  • Flashfire Fist[Passive] While active, fire skills deal more damage, but heat builds up faster.
