Quirks / Heroes

New Order

Used by: Star and Stripe

Touch a target and call its name to set a new rule on it.

Passives

  • New Order ①[Limit of Invincibility] Only up to 2 rules can be active at once.
  • New Order Rejects Other Quirks[Passive] If New Order is stolen by All For One, it keeps erasing the stolen Quirks until New Order is given to someone else.
  • Body Is Strengthened The Quirk target gains attack and mobility.
  • Cannot Guard The Quirk target can no longer guard.
  • Weakened The Quirk target's attack decreases.
  • Cannot Use Quirks The Quirk target can no longer use Quirks.
  • Cannot Jump The Quirk target can no longer jump.
  • Cannot Eat The Quirk target can no longer eat food.
  • Heart Stops on Movement The Quirk target dies if it moves.
